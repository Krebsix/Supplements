# MySuplea Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Statische Landingpage DE/EN für MySuplea in `web/` mit Loops-Beta-Formular, dazu Umzug der generierten Rechtsseiten unter dieselbe Domain.

**Architecture:** Astro-Projekt in `web/` (statisches Output, kein Adapter). Ein Wörterbuch je Sprache (`src/i18n/de.ts`, `en.ts`) mit gemeinsamem Typ; zwei Seiten (`/`, `/en/`) rendern dieselbe `Landing`-Komponente. Rechtsseiten werden weiterhin aus `data/legalContent.js` generiert, jetzt nach `web/public/`. Tokens liegen in `src/styles/tokens.css` und werden per Test gegen `theme.js` geprüft.

**Tech Stack:** Astro (aktuell), TypeScript strict, @astrojs/sitemap, sharp (nur Dev, für OG-Bild), Node 24, Vercel.

**Spec:** `docs/superpowers/specs/2026-08-30-website-design.md`

## Global Constraints

- Keine Hex-Werte in Komponenten; nur CSS-Variablen aus `src/styles/tokens.css`. Werte wörtlich aus `theme.js`.
- Keine Gedankenstriche („—", „–") in Nutzertexten (DE und EN). Echte Umlaute (ä/ö/ü), nie ae/oe/ue.
- Verbotswörter DE: hilft, wirkt, heilt, behebt, empfohlen. EN: cure, heals, treats, boosts, recommended, you should.
- Formulierung „ohne Konto nutzbar" / „works without an account", nie „kein Konto".
- Keine externen Skripte, Fonts, Stylesheets. Keine Cookies. Kein Analytics.
- Keine Preiszahlen. Keine Emojis als Icons. Keine vollrunden Pillen (Radius max 20, Knöpfe 10).
- Genau eine H1 je Seite. `color-scheme: light`.
- Commits als Conventional Commits, Code Englisch, Kommentare Deutsch. Kein Push ohne OK.

### Task 2: Wörterbücher DE/EN und i18n-Test (TDD)

**Files:**
- Create: `web/tests/i18n.test.mjs`, `web/src/i18n/de.ts`, `web/src/i18n/en.ts`

- [ ] **Step 1: Test schreiben**

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { de } from '../src/i18n/de.ts';
import { en } from '../src/i18n/en.ts';

function flatten(obj, prefix = '') {
  return Object.entries(obj).flatMap(([k, v]) =>
    typeof v === 'object' && v !== null ? flatten(v, `${prefix}${k}.`) : [[`${prefix}${k}`, String(v)]]);
}
const FORBIDDEN = {
  de: [/\bhilft\b/i, /\bwirkt\b/i, /\bheilt\b/i, /\bbehebt\b/i, /\bempfohlen\b/i, /\bkein Konto\b(?! nötig)/i],
  en: [/\bcure/i, /\bheals\b/i, /\btreats\b/i, /\bboosts\b/i, /\brecommended\b/i, /\byou should\b/i, /\bno account\b/i],
};
test('same keys in both dictionaries', () => {
  assert.deepEqual(flatten(de).map(([k]) => k), flatten(en).map(([k]) => k));
});
for (const [lang, dict] of [['de', de], ['en', en]]) {
  test(`${lang}: no dashes, no forbidden words, no ae/oe/ue`, () => {
    for (const [key, value] of flatten(dict)) {
      assert.doesNotMatch(value, /[—–]/, `${key} contains a dash`);
      for (const re of FORBIDDEN[lang]) assert.doesNotMatch(value, re, `${key} matches ${re}`);
      if (lang === 'de') assert.doesNotMatch(value, /\b\w*(ae|oe|ue)\w*\b/i ? /(?<![aA])ue(?![a-z]*$)/ : /$^/, `${key}`);
    }
  });
}
```

(Node 24 lädt `.ts` nativ per Type-Stripping; `satisfies` ist erlaubt. Die ae/oe/ue-Prüfung ist eine Liste konkreter Wörter: `aendern, ueber, fuer, koennte, praeparat, naehr, zusaetz, waehl, spaeter, loesch, veroeffentlicht, obergrenze` als Regex `/(aendern|ueber|fuer|koennt|praeparat|naehr|zusaetz|waehl|spaeter|loesch|veroeffentlicht)/i`, statt der Heuristik oben.)

import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync, existsSync } from 'node:fs';

const pages = ['dist/index.html', 'dist/en/index.html', 'dist/datenschutz/index.html', 'dist/impressum/index.html', 'dist/nutzung/index.html'];
for (const p of pages) {
  test(`${p} exists with one h1 and no external resources`, () => {
    assert.ok(existsSync(p), `${p} missing, run npm run build`);
    const html = readFileSync(p, 'utf8');
    assert.equal((html.match(/<h1[\s>]/g) ?? []).length, 1);
    assert.doesNotMatch(html, /<script[^>]+src="https?:/);
    assert.doesNotMatch(html, /<link[^>]+href="https?:/);
  });
}
for (const p of ['dist/index.html', 'dist/en/index.html']) {
  test(`${p} has hreflang de, en, x-default`, () => {
    const html = readFileSync(p, 'utf8');
    for (const l of ['de', 'en', 'x-default']) assert.match(html, new RegExp(`hreflang="${l}"`));
  });
}
